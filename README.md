\# Sistema de Estoque — Python + Streamlit + SQLite



Sistema de gerenciamento de estoque desenvolvido em Python utilizando Streamlit e SQLite.



\## Funcionalidades



\* Cadastro de produtos

\* Edição de produtos

\* Controle de quantidade em estoque

\* Entrada de produtos

\* Saída de produtos

\* Histórico de movimentações

\* Controle de estoque mínimo

\* Alerta de estoque baixo

\* Pesquisa de produtos

\* Dashboard com indicadores

\* Cálculo do valor total do estoque

\* Banco de dados SQLite



\## Tecnologias



\* Python

\* Streamlit

\* SQLite

\* Pandas



\## Como executar



Clone o repositório:



```bash

git clone https://github.com/theagosakai/sistema-estoque-python.git

```



Entre na pasta:



```bash

cd sistema-estoque-python

```



Instale as dependências:



```bash

pip install -r requirements.txt

```



Execute a aplicação:



```bash

streamlit run app.py

```



A aplicação estará disponível em:



```text

http://localhost:8501

```



\## Estrutura



```text

sistema-estoque-python/

│

├── app.py

├── requirements.txt

├── README.md

├── .gitignore

```
